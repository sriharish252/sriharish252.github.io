Attention Ledger

A private record of where my time and attention actually go across my Windows laptop and iPhone. Small collectors on each device write to storage I own, my laptop and my own iCloud Drive, and the only reports it ever produces are exported for me to read.

Why

Screen-time apps tell you how long each app was open. I wanted to know what I was actually doing, when I drifted, and what pulled me away, across both screens at once, without handing a minute-by-minute record of my life to anyone.

Private by design

No keystrokes, screenshots, audio, message content, full web addresses or raw window titles, ever. Only app names, website domains and cleaned titles for apps I allow.

Only storage I own

A database on my laptop and a folder in my own iCloud Drive. No telemetry, no accounts, no servers, no third-party analytics.

I stay in control

Pause one device or all of them from any of them. Block any app or site, and it is logged only as Private so the day still adds up.

Independent parts

Each collector was built, tested and used on its own device for at least a day before any data was combined.

How it works

Laptop agent

Reads
The foreground window's app, time since the last input (not the input), and whether the screen is locked
Never reads
Keys, clicks, screen contents, or a window title unless the app is on my allowlist, and then only a cleaned piece of it
Writes to
A database in my Windows profile, exported as one file per day
Pause
Tray menu or a hotkey, for this laptop or all devices

Browser extension

Reads
The active tab's address, reduced to its domain the moment it is seen, and which tabs are playing sound
Never reads
Page contents, paths, search terms, or anything from browser pages, local files or local addresses
Writes to
The browser's local storage, then the laptop agent. Browser sync is never used
Pause
The toolbar popup, for this browser or all devices

iPhone automations

Reads
That an app opened or closed, plus Focus mode, charger and step-count signals
Never reads
Anything inside an app. Apple gives no other app this data, which is why it runs through Shortcuts
Writes to
One file per day in my own iCloud Drive, with a local fallback on the phone if iCloud is briefly unavailable
Pause
A Home Screen, Control Center or Action Button shortcut

Analysis

Reads
The day files from both devices, and nothing else
Works out
Time on a task, switches per hour, the longest focus stretch, every distraction and phone check
Writes to
A report and a spreadsheet file in a folder on my laptop
Needs
Python and nothing to install: no packages, no network

What is never recorded

  • Keystrokes or mouse input
  • Screenshots or screen contents
  • Audio, messages, or what was playing
  • Full web addresses, paths or search terms
  • Raw window titles
  • Names of apps and sites I block: they appear as Private

What a record can hold

A time with its UTC offset, the device, the collector, the kind of event, an app name or a domain, a length, and a short label. The format allows nothing else: a collector that tried to add a field, like a full address, would fail validation. Try it below.

        Hard parts
        
      
          
        
        1. 
          
          iPhone
          
          
          
            
          iOS won't share app usage
          
            
          Screen Time data can only be shown inside Apple's own sandboxed view and can't be exported. Personal Shortcuts automations ("when Instagram opens, run this") are the one route into a file I own, so every app gets its own automation running two small Scriptable scripts.
          
          
          
        
          2. 
        
        2. 
          
          iPhone
          
          
          
            
          There is no "phone locked" signal
          
            
          An app that never logs a close ends at the first of: the next app, activity on the laptop, a Sleep Focus or charger change, or a cap of 45 minutes for video, calls and maps and 20 for everything else.
          
          
          
        
          3. 
        
        3. 
          
          Laptop
          
          
          
            
          Two collectors see the same screen
          
            
          The agent sees "the browser is in front"; the extension knows which site. The timeline prefers the more specific one, and anything in front for under three seconds is folded into what came before, so alt-tabbing past windows doesn't count as switching.
          
          
          
        
          4. 
        
        4. 
          
          Everywhere
          
          
          
            
          A pause has to reach every device, without a server
          
            
          The shared iCloud folder doubles as the switch. The laptop checks it every few seconds, and the phone checks it each time an automation runs, so a pause started anywhere is honoured everywhere, usually within a minute.
          
          
          
        
          5. 
        
        5. 
          
          Format
          
          
          
            
          Making a leak impossible, not just unlikely
          
            
          The log format allows a fixed set of fields and nothing else. Adding a new kind of data means changing the format, its validator and its examples together, so a collector can't start recording more by accident.
          
          
          
        
          6.
