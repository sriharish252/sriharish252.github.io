Selected work

Computational Website Generation A portfolio that designs itself: a new, accessible design on every visit, never a near-repeat. Flagship, 2026
Problem
A site built from a template looks like every other site built from it. Can a page design itself, new each time, without ever shipping one that is hard to read or a near-repeat?
Approach
A page is an 82-axis vector in seven layers, from palette and type to imagery and motion. Random samples one of 14 archetype regions; Zod clamps every range, contrast is asserted rather than repaired, and an effects budget keeps it restrained. A draw must clear an Oklab-based novelty floor and change at least four of the seven layers before it is compiled to CSS variables.
My role
Sole developer: the design space, the engine, the tests and the deployment.
Outcome
A static site with 10 curated themes and 242 tests, including a 1,000-draw run that never repeats a recent page. Any generated design can be shared as a link that reopens it exactly.

TypeScript, Next.js, React, Zod, Vitest, GitHub Actions

Attention Ledger A private record of where my time goes across my laptop and iPhone, kept only on my own devices and my own iCloud Drive. Personal, 2026

What one record holds

{ "ts": "2026-11-09T09:25:30-05:00",
  "device": "laptop",
  "event": "span",
  "app": "msedge.exe",
  "domain": "github.com",
  "duration_s": 240 }

The schema allows no other fields, so a collector can't quietly start logging something new, like a full address, without the format changing first.

What is never recorded

  • Keystrokes or mouse input
  • Screenshots or screen contents
  • Audio, messages or what was playing
  • Full web addresses or page paths
  • Raw window titles
  • Names of apps I block: they appear as Private, so totals still add up
Problem
I wanted an honest answer, at the end of each day, to where my time and attention went across my laptop and phone, without handing a minute-by-minute record of my life to a store app or someone else's cloud.
Approach
Three small collectors, one per surface, each built and tested on its own: a Windows agent, a Chromium extension and iPhone Shortcuts automations, the one route iOS allows into a file I own. All write one strict JSON Lines format. An analysis step merges the devices into one timeline and finds focus stretches, switches and the moments I drifted.
My role
Sole designer and developer, and the only user.
Outcome
In daily use on my laptop, browsers and iPhone, with about 250 automated tests run on Windows and Ubuntu. I can pause one device or all of them and block any app or site from either side. The data is mine to export and analyse, and it is never shared.

Python, SQLite, Win32, JavaScript (Manifest V3), iOS Shortcuts, Scriptable, iCloud Drive, JSON Schema, pytest

Social Media Content Editor Paste a post or an article link, and a team of agents rewrites it for Instagram, TikTok and LinkedIn. 2024
Problem
One post rarely fits every platform: each has its own character and hashtag limits, audience and tone.
Approach
One CrewAI crew per platform, all running at once: an editor drafts, a critic reviews and the editor rewrites. Platform rules live in a single TOML file, LangChain's Tavily tools turn a link into article text and find hashtags in current use, and each task returns a Pydantic model.
My role
Sole developer.
Outcome
A post per platform with its hashtags, a character count checked against the limit and the critic's notes. A no-invented-facts rule stops the made-up quotes the first version produced, and the tests run against a stubbed model, with no API key.

Python, CrewAI, LangChain, Gemini, Streamlit

Goodreads Review Sentiment Finds books whose star ratings and written reviews disagree. 2019
Problem
A star rating is a blunt summary. Does it match what readers actually write?
Approach
Every review is scored with VADER and with a DistilBERT transformer, cached in SQLite, and compared per book once both scales are standardised: a book diverges when its sentiment and its stars sit at least one standard deviation apart.
My role
Sole developer.
Outcome
Across 909 poetry books and 23,895 reviews, the transformer flags 30% of books and VADER 39%. VADER mistakes the subject for the opinion, reading war and elegy poetry as negative even under five-star reviews.

Python, VADER, DistilBERT, SQLite, pytest

Smart Home Security on BeagleBone A multithreaded home security controller in C, built on a BeagleBone Black. 2023
Problem
A security controller has to watch several sensors at once and answer each one without missing the others.
Approach
Three concurrent POSIX threads: a PIR sensor triggers the alarm while the system is armed, a four-button keypad sequence arms and disarms it, and a water sensor read through the on-board ADC raises the alarm on a leak. GPIO is driven through Linux sysfs.
My role
Team lead of six on the term project for Real-Time and Embedded Systems at George Mason. I planned the control logic and wrote most of the C.
Outcome
A controller that runs all three tasks concurrently on the board, with standalone component tests for the keypad and the water sensor.

C, POSIX threads, BeagleBone Black, Linux GPIO
